ClickFix Guard demo

"ClickFix" pages show a fake CAPTCHA or error, secretly copy a command to your clipboard, and ask you to paste it into Win+R or Terminal. Try the simulated attacks below, with and without the extension.

Click a scenario to check whether you're protected
These demos are safe. Every command points to reserved test addresses (RFC 5737 IPs and .invalid domains) that cannot connect, so nothing can download or run. Still: never paste commands from a website into Run, PowerShell or Terminal.

Install ClickFix Guard

Free and open source. No network requests, no telemetry: everything runs in your browser.

Firefox / Zen

  1. Download clickfix-guard-…-firefox.xpi from the latest release.
  2. Open about:addons, click ⚙ → Install Add-on From File… and pick the file.
Latest release

Chrome / Edge / Brave

  1. Download and unzip clickfix-guard-…-chrome.zip.
  2. Open chrome://extensions, turn on Developer mode, click Load unpacked and pick the folder.
